# QR Code Based Student Attendance Management System

A full-stack web application that streamlines student attendance tracking using QR code scanning. Built as my HNDIT final-year project, it allows quick check-ins via QR codes and gives admins an easy way to manage records and generate attendance reports.

## Features
- QR code-based attendance marking
- Admin dashboard for managing students and records
- Attendance report generation
- Secure login system

## Tech Stack
- PHP 8.x
- MySQL
- Bootstrap 5
- XAMPP

## Setup
1. Clone or download this repository
2. Import the database file into phpMyAdmin
3. Update database credentials in the config file
4. Run the project on XAMPP (Apache + MySQL)
